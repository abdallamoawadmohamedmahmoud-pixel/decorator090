# Decorator Website with Enhanced Authentication System

موقع احترافي لشركة Decorator مع نظام مصادقة مُحسَّن وقاعدة بيانات مستخدمين متكاملة.

## 🌐 الصفحات العامة

### 1. الصفحة الرئيسية (index.html)
- Hero Section جذاب مع CTA للواتساب
- قسم لماذا تختارنا مع 4 مميزات
- معاينة لأحدث الأعمال
- عرض خدمات رئيسية
- CTA نهائي للتواصل

### 2. معرض الأعمال (portfolio.html)
- Grid layout لعرض المشاريع
- Before/After slider تفاعلي
- تفاصيل كل مشروع مع أزرار CTA

### 3. الخدمات (services.html)
- 4 خدمات رئيسية مفصلة
- وصف شامل لكل خدمة
- صور عالية الجودة

### 4. تواصل معنا (contact.html)
- نموذج تواصل بسيط
- زر واتساب مباشر
- خريطة جوجل
- معلومات التواصل

### 5. من نحن (about.html)
- نبذة عن الشركة
- الرؤية والرسالة
- إحصائيات الشركة
- قيم الشركة

### 6. صفحة التسجيل (register.html) - **جديدة**
- نموذج تسجيل مُحسَّن مع تحقق فوري
- التحقق من صحة البريد الإلكتروني
- التحقق من صيغة الأرقام المصرية
- مؤشر قوة كلمة المرور
- معالجة خاصة لبريد المالك
- شروط وأحكام

### 7. صفحة تأكيد البريد (confirm-email.html) - **جديدة**
- واجهة تأكيد البريد الإلكتروني
- التحقق من رموز التأكيد
- معالجة الأخطاء
- إعادة إرسال التأكيد
